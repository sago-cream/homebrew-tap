# homebrew-tap

Homebrew casks maintained by [sago-cream](https://github.com/sago-cream).

## Install

```bash
brew install --cask sago-cream/tap/airloom
brew install --cask sago-cream/tap/comux
brew install --cask sago-cream/tap/handytab
brew install --cask sago-cream/tap/sago-drop
```

## Casks

- [Airloom](https://github.com/sago-cream/Airloom) — Native video wallpapers and animated lock screens.
- [Comux](https://github.com/sago-cream/comux) — Codex account limits in the macOS menu bar.
- [HandyTab](https://github.com/sago-cream/handy-tab) — Open a favorite browser tab with a hand wave or trackpad tap.
- [Sago Drop](https://github.com/sago-cream/sago-drop) — Upload files from the macOS menu bar.
